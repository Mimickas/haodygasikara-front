# FINALISATION COMPLÈTE DU PROJET

## OBJECTIF PRINCIPAL

Je veux maintenant une **finalisation complète, professionnelle et approfondie de tout le projet**.

Il ne s'agit pas simplement de corriger quelques bugs.

Je veux un véritable :

* audit ;
* nettoyage ;
* suppression du code inutile ;
* nettoyage BDD ;
* correction des fonctionnalités ;
* harmonisation Front-office / Admin ;
* harmonisation du design ;
* correction des incohérences ;
* amélioration des composants ;
* vérification des parcours ;
* vérification responsive ;
* vérification interne et externe ;
* finition générale du projet.

**NE PAS SE LIMITER AUX PROBLÈMES QUE JE CITE.**

Les exemples ci-dessous servent de références pour identifier également toutes les incohérences similaires dans le reste du projet.
